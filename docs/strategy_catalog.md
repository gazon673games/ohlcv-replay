# Локальные исходники алгоритмов

Настройка `strategies.sdk_catalog_path` задаёт плоскую локальную папку Python-файлов.
Переменная `WORKBENCH_SDK_CATALOG_PATH` имеет приоритет. Доступ к файлам доверенный:
перед исполнением хост фиксирует исходники, зависимости, параметры и их fingerprint.

Машинные настройки хранятся в игнорируемом `settings/workbench.local.json`.
Публичный SDK содержит только контракты и техническую заготовку без торговых сигналов.
Пользовательские алгоритмы, пресеты, результаты и их описания не публикуются.

Сохранённые варианты и поставленные в очередь запуски используют отдельные снимки.
Изменение исходника не меняет уже работающий запуск. Правки общего файла проверяют
ревизию и сохраняют предыдущую версию. Некорректный каталог не подменяется другим.
